# How the mock data was made

All data in this project is mock data. It was generated by `generate_data.py`
(fixed seed 42) and does not come from real aiTransform users. Anyone can
regenerate the exact same files by running the script again.

## Coverage
- 35 days: 3 October 2026 to 6 November 2026.
- 1,875 rows, 3,038 sessions in total.
- Each row: date, hour (0-23, PKT), tool, file_type, sessions.
- Files: `data/usage.csv` and `data/usage.json` hold the same rows.

## Tools and file types
The six tools match the tools shown on aitransform.com: AI Writer, AI Image
Generator, AI Code Generator, AI Chatbot, Speech to Text, AI VoiceOver.
File types per tool:
- AI Writer: txt, docx, pdf
- AI Image Generator: png, jpg
- AI Code Generator: py, js, html
- AI Chatbot: txt
- Speech to Text: mp3, wav
- AI VoiceOver: mp3, wav

## How the numbers were produced
For each (day, hour, tool) cell, an expected session count was computed as:

expected = 85 (base sessions per day) x day factor x trend x hour weight x tool weight

- Day factor: weekdays 1.15, weekends 0.65. Weekends are quieter by design.
- Trend: linear rise from 0.90 on day 1 to 1.10 on day 35, a slight upward trend.
- Hour weights: peak 10:00-13:00 and 19:00-22:00 PKT, very quiet 02:00-06:00.
  The 24 weights are normalised so they sum to 1.0.
- Tool weights: AI Writer 0.30, AI Image Generator 0.22, AI Code Generator 0.15,
  AI Chatbot 0.14, Speech to Text 0.10, AI VoiceOver 0.09.
- The session count for each cell is a Poisson sample of the expected value
  (Knuth's method for small means, normal approximation above 30). Cells with
  0 sessions are not written out.
- File type per row is a weighted random choice from the tool's file types.

## Assumptions and limits
- The base level (about 85 sessions per day), the tool weights, the hour
  pattern, and the trend are invented for demonstration. They are plausible
  shapes for a small AI tools site, but they are not measured from real usage.
- No real user, account, payment, or location data exists in this dataset.
- The dashboard reads the JSON file in the browser. It works only when the
  folder is served over HTTP (see README.md), not when index.html is opened
  directly from disk, because browsers block fetch from file URLs.
